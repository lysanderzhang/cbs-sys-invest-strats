## Main findings

| Full sample, 217 months | CAGR | Excess-return Sharpe | Month-end MDD |
|---|---:|---:|---:|
| Dual momentum | 6.08340% | 0.58737 | -14.05541% |
| Static eight-asset portfolio | 6.52178% | 0.48750 | -30.65167% |
| Fixed 2pp switching buffer | 6.33698% | 0.61771 | -14.25792% |

Dual reduces drawdown but sacrifices return. In 2012–June 2026 its Sharpe is 0.51158, below Static's 0.54822. Neither its extension Sharpe difference against Static nor Buffer's difference against Dual is distinguished from zero by the reported paired block bootstrap.

The extra-credit buffer retains an eligible incumbent unless the relative winner leads by more than two percentage points. Absolute exits remain immediate. Annual dollars traded fall from 430.67160% to 353.81480% of NAV. Costs count both purchases and sales. At 10 bp per dollar, CAGR is 5.62734% for Dual and 5.96127% for Buffer. No threshold optimization is performed.

## Output map and conventions

- results/tables/: full and period-specific performance, individual assets, module ablations, correlations, utilization, costs, common-window lag comparison, paper Table 10 transcription and bootstrap intervals.
- results/timeseries/: arithmetic monthly returns, wealth, momentum scores, all five rules' holdings, dated module allocations and drift-adjusted turnover.
- results/figures/: five vector PDFs, all integrated in the report appendix.
- results/verification/: independent reconstruction, pytest output, report evidence, preflight checks and visual-review hash.
- references/: unchanged supplied documents.
- submission/: report, convenience source copy, implementation archive and manifests. ZIP and convenience TeX are Git-ignored; canonical source and final PDF are intended for tracking.

CAGR compounds monthly returns and annualizes with 12/N; arithmetic annualization is 12 times the monthly mean. Volatility uses sample standard deviation times sqrt(12). Sharpe uses mean monthly returns less SHV, divided by sample standard deviation of those excess returns, times sqrt(12). MDD includes initial capital. ES averages returns at/below the interpolated 5% quantile. Skewness and excess kurtosis are bias-adjusted. Stress-table wealth returns are not annualized. Time-series returns use decimal units; table headings ending _pct use percentage points. CSVs retain 17 significant digits; report results use five decimals.

## Verification and limits

Twenty tests cover compounded signals, latest-month inclusion, ties, weights, exact date alignment, future-data perturbations for all active rules, buffer exits, turnover drift, Sharpe, initial-capital drawdown, data integrity and common periods. An independent implementation reads the original daily JSON, reconstructs month ends and all 217 baseline returns and 1,953 weights, and calculates eight performance measures: 2,178 comparisons with zero maximum return difference. It does not import production financial functions. Numerical output hashes protect against stale checks; report narrative evidence and tables link to exported results. All twelve PDF pages are rendered and inspected. A clean ZIP extraction reproduced all 27 numerical CSVs and the generated report source byte-for-byte, and all 20 tests passed there as well.

Limitations: one vendor; possible historical revisions; proxy/duration mismatches; short paper overlap; monthly rather than intramonth drawdowns; frictionless month-end execution; illustrative costs, no taxes/capacity estimate; retrospective universe and extra-credit-rule choices. An additional month of lag uses the same 216 months for both rules. It is a sensitivity, not a selected replacement or precise next-open execution test. The exposure control uses a full-sample mean and is descriptive. Factor-model alpha analysis is omitted as permitted.
