## Main results

- **Problem 1.** With equal-marginal-volatility weights (each component scaled to unit volatility),
  adding n strategies raises the Sharpe ratio iff
  `rho_old,new < s + (n/2) s^2 - (1 + (n-1) rho_new)/2`, `s = SR_new/SR_old`.
  For n = 1 the bound is `s + s^2/2 - 1/2`: -0.5 at `SR_new = 0`, 0 at `SR_new = 0.41421 SR_old`,
  1 at `SR_new = SR_old`. Under this weighting the simple averages of the Sharpe ratios and
  correlations are exact sufficient statistics, so relaxing assumptions (b)-(d) changes nothing.
- **Problem 2.** `g(w) ~ E[log(1+wR)] ~ w mu - w^2 sigma^2/2`, so `w* = mu/sigma^2` and
  `g* = SR^2/2`. With cash at r: `w* = (mu-r)(1+r)/sigma^2`, `g* = log(1+r) + SR^2/2`.
  With several risky assets the problem separates into maximizing the risky portfolio's Sharpe
  ratio (tangency), then levering it.

## Method choices

1. **Assumption (e)** is read as equal-marginal-volatility (inverse-volatility) sizing: notional
   `k/sigma_j` per component, the existing portfolio treated as one component.
2. **2(b) approximation.** The Daniel–Moskowitz appendix is not among the supplied files; the
   write-up uses the second-order expansion `log(1+x) ~ x - x^2/2` with `E[R^2] ~ sigma^2`.
3. **Numerical example (Problem 2).** Illustrative per-period `mu = 0.008`, `sigma = 0.11`,
   lognormal gross return (keeps `1 + r + w(R-r) > 0` on `0 <= w <= 1`), `r = 0.002`. Exact
   expected log growth uses 80-point Gauss–Hermite quadrature; simulation uses 120 periods and
   20,000 paths (seed 9339). It is not an empirical estimate.
4. **Heterogeneous examples (1.5–1.7).** Eight random valid correlation matrices and Sharpe
   ratios, seed 9339; the matrix Sharpe ratio is compared with the closed form at the averages.
